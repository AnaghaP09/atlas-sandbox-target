# ATLAS sandbox target

A small demonstration repository for [ATLAS](https://github.com/AnaghaP09/atlas). ATLAS hands
bounded, human-approved tasks to a sandboxed coding agent and publishes the result here as a
draft pull request for review.

The code in this repository is a small Go package written for the demo; it is not taken from any
other project. Changes arrive only as draft pull requests and are never merged automatically.
